## 1. Issue inventory (severity-ranked)

### 🔴 CRITICAL — blocks all real usage
- **C1 · Auth/login broken end-to-end.** Four FE↔backend contract breaks after the Phase-S proxy cutover:
  (1) login action sends `{mobile}`, backend requires `{phone}` (whitelist 400 — verified live);
  (2) `verify-otp` omits required `clientId`; (3) action reads `data.data.token`, backend returns `accessToken`
  → empty cookie; (4) session stored in httpOnly cookie but `lib/api-client.ts:20` reads `localStorage.token`.
  Plus **no `middleware.ts`** route guard. **No real user can log in.** Backend login works with the correct
  contract (`{phone,otp,clientId}` → 200 `accessToken`).
- **C2 · Pervasive auth-attachment inconsistency.** Many FE pages don't attach the Bearer token → 401 → silent
  demo/mock fallback. Verified-by-401: admin Overview, KYC Submissions, Approvals, Visibility, Payouts,
  partner Wallet. Pages routed through `api-client` `authHeader` DO attach (TDS, credits, targets, invoices,
  schemes, sales/kyc) and show real data.

### 🟠 HIGH — money / data-integrity / "fake success"
- **H1 · Dead write-paths (success UI, no persistence):** KYC approve/reject (sales + admin), sales redemption +
  OTP, visibility submit, invoice generation, partner support, enrollment OTP. (static + runtime)
- **H2 · `payouts.processBatch`** un-transactioned + read-then-write (no guarded claim) → duplicate TdsRecords /
  double INITIATED flip / no rollback. (`api/src/payouts/payouts.service.ts:280-408`)
- **H3 · Gift Catalogue 500 (verified live).** `api/src/rewards/rewards.service.ts:932-950` `adminListCatalog`
  passes the raw query-string `limit` to Prisma `take` → `PrismaClientValidationError`. FE always sends
  `?limit=200` → 500; the admin catalogue breaks once any reward row exists. (Instance of gap #26.)
- **H4 · Fabricated dashboards.** Overview (fetch 401 → fake "4,821 partners / ₹2.14 Cr") + 4 sub-dashboards
  (no fetch at all; hardcoded 248 outlets / 221 approved over an empty DB).
- **H5 · Empty DB + broken seed.** `api/prisma/seed.ts:24` does `new PrismaClient()` with no driver adapter →
  throws under Prisma 7; not wired into `prisma.config.ts`. No reproducible environment.

### 🟡 MEDIUM
